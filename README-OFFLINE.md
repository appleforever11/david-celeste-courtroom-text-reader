# David & Celeste Courtroom Text Reader

This package contains a standalone, local HTML reader for the David Burke
(D4vd) and Celeste Rivas Hernandez text messages described during the July 24
and July 27, 2026 preliminary-hearing testimony.

Created and maintained by [@applepkmn11 on X](https://x.com/applepkmn11).
If you use the reader in reporting, a YouTube video, podcast, or social post,
please credit the creator and link the canonical project page:

https://appleforever11.github.io/david-celeste-courtroom-text-reader/

Important: this is a community transcription reconstructed from courtroom
notes and published reporting. It is not an official forensic message export,
complete discovery, or an official court exhibit. The source itself warns that
some text may be incomplete or inaccurate.

Content warning: the material discusses alleged child sexual abuse, pregnancy,
abortion, threats, and violence.

## Open it on macOS

1. Download and unzip the package.
2. Open the extracted `David-Celeste-Courtroom-Text-Reader` folder.
3. Double-click `david-celeste-imessage-player.html`.
4. If macOS asks which app to use, choose Safari, Chrome, Firefox, or Edge.

## Open it on Windows

1. Download the ZIP file.
2. Right-click it and choose **Extract All**. Do not run the reader from inside
   the ZIP preview.
3. Open the extracted `David-Celeste-Courtroom-Text-Reader` folder.
4. Double-click `david-celeste-imessage-player.html`.
5. If prompted, choose Edge, Chrome, or Firefox.

## Open it on Linux

1. Extract the ZIP file.
2. Open the extracted folder.
3. Double-click `david-celeste-imessage-player.html`, or drag the file into a
   Firefox or Chrome window.

## How to use the reader

- Use **Both hearing days**, **Day 4**, or **Day 5** to filter the transcript.
- Filter by David or Celeste, or search for a word or phrase.
- Select **Play** for browser-based audio reading. Voice availability depends
  on the computer and browser.
- Use bookmarks and pause points to save places in the transcript.
- Progress, bookmarks, and pause points are saved only in that browser on that
  computer.
- The reader works locally after extraction. It does not require installation
  or an account.
- The version badge checks GitHub for a newer release. Use **Check for updates**
  or the canonical project page to get future versions.

Keyboard shortcuts:

- Left arrow: previous visible message
- Right arrow: next visible message
- Space: play or stop
- `/`: focus the search box

## Troubleshooting

- If you see raw HTML code, right-click the file, choose **Open With**, and
  select a web browser.
- If the filename ends in `.html.txt`, rename it so it ends in `.html`.
- Keep the `source` folder beside the HTML file so the saved-workbook link
  continues to work.
- Extract the ZIP before opening the reader. Browser storage and source links
  may not work correctly from an archive preview.
